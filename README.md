# Server-configuration-auto-deployment-using-Ansible

An automated **Linux server deployment and configuration project** using Ansible to remotely install and configure an Apache HTTP server on a CentOS managed node from an Ubuntu-based control node.

The project uses **Ansible's agentless SSH architecture and YAML playbooks** to automate software installation, website deployment, service management, and firewall configuration. It demonstrates a repeatable approach to infrastructure automation and can be extended to multi-server provisioning, security hardening, CI/CD, and Infrastructure as Code (IaC).

### Technologies
- Ansible
- OpenSSH / SSH
- Linux (Ubuntu & CentOS)
- Apache HTTPD
- YAML
- Firewalld
- Infrastructure as Code (IaC)
